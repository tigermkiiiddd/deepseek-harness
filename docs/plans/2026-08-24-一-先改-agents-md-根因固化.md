# 一、先改 AGENTS.md（根因固化）

在根 `AGENTS.md` 的 Conventions 段加两条规则（紧挨 "Explicit > implicit at package boundaries"）：

1. **Minimalism constrains scope, not requirements.** The preference for small diffs decides what a change includes — never whether a stated requirement is met or how deep the fix must go. When a requirement (especially an architectural one such as peer treatment of parallel entities) is not satisfied by a local patch, do not ship the patch citing minimality; satisfy the requirement at its owning layer or report the gap explicitly.
   （最小化改动约束的是范围，不是需求和修改深度。需求不满足时，不得以"改动小"为由交付补丁；要么在所属层把需求做足，要么明确上报缺口。）

2. **Approval gates are requests, not avoidance.** A rule that requires user approval before changing a surface (wire API, public exports, protocol fields) means "ask before changing." It never licenses routing around the gated change with a cheaper workaround. If the correct fix needs a gated surface, propose it for approval; do not silently pick the ungated inferior path.
   （"需用户批准"的本意是改之前先问，绝不授权绕开被批准的改动去走更便宜的错误路径。正确修法需要动受控面时，提出批准请求；不得静默选择不受控的次优路径。）

验证：`verify-doc-budgets` 门通过（超预算则按 "Editing these instructions" 段提上限）。

# 二、成员对等实现（按需求深度做足，不再分档）

## Wire（走批准，本计划即请求）
1. `session.create` payload + `agentId?: string`（不透明 token，缺省=主实例；与 workspaceId/cwd 互斥）。响应不变，host 返回完整会话 id。
2. `SessionSummary` 行 + `host/session-added` 帧 + `agentId?: string`（缺省=主实例）——归属是数据，不是 id 前缀。
3. `team.sessions` 响应项改为 host 拼好的**完整会话 id**。

## Host（packages/host/apiproxy）
- `sessions.create`：`agentId` 存在 → 路由到该成员 bridge（复用现有 team.newSession 原语）→ host 拼 id → 广播行帧（带 agentId、blank:true）→ 返回完整 id；错误映射现有 team 错误码。缺省走现主路径不变。
- session.list 成员行 + 新话题帧：填 `agentId`。
- blank 对等：成员话题首条 user prompt 到达时清除 blank（host 经手所有成员消息，在 prompt 路由点做；先核对主实例 blank 清除机制再镜像）。→ 新话题显示"新会话"，编号标题消失。
- `team.sessions`：返回完整 id。

## Client（六处分叉全删）
1. `startSession` 单一路径：读当前行 `agentId` → `sessions.create({agentId})` → open；否则现有逻辑。删 team.newSession 调用、id 拼装、refresh-retry（create 响应已保证行在列表，manager.ts:541）。
2. 侧栏 scope 过滤改读行数据 `agentId`，不再解析 id。
3. 成员话题落 Ungrouped（free session 同路）：删 `memberWorkspaceOf`、tree.ts cwd-matching 循环、`sameWorkspacePath`（无他用则删）。
4. Rows 行菜单：删成员特判；不支持的操作由 host 拒绝（W1-W7 已实现），走正常错误路径。
5. 拖拽排序：成员行走 ungrouped 账户，与主 agent 未分组同路；删特判子句。
6. ui-team：openMember 用 `team.sessions` 完整 id + `sessions.create({agentId})`；删本地拼装与前缀 import。roster 管理留在 team.*（team 表面，合理）。
